# Knowledge Base

Esta carpeta contiene una base de conocimiento sintetica del proyecto. No reemplaza la documentacion existente ni copia sus archivos: organiza el conocimiento ya documentado para poder navegarlo como wiki.

## Estructura

- `wiki/`: notas curadas y enlazadas entre si. Es la puerta de entrada para entender arquitectura, componentes, decisiones y conceptos.
- `raw/`: espacio reservado para fuentes externas futuras, como PDFs, videos, reuniones, chats, normativa o documentos recibidos. No contiene copias de documentos existentes del proyecto.
- `working/`: espacio para notas temporales, borradores, preguntas abiertas y sintesis en construccion.
- `archive/`: espacio para notas obsoletas o versiones antiguas de analisis de conocimiento.

## Regla De Uso

La wiki debe sintetizar y enlazar fuentes existentes, no duplicarlas. Cuando cambie el proyecto, actualizar primero la documentacion fuente que corresponda y luego reflejar la sintesis en `wiki/`.
