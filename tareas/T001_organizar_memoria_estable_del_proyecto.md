# T001 - Organizar memoria estable del proyecto

Estado: finalizada

Prioridad: alta

Area: documentacion / forma de trabajo

Fecha de creacion: 2026-06-30 Fecha de cierre: 2026-06-30

### Contexto

El proyecto todavia no esta formalmente versionado y se viene
trabajando con bastante contexto acumulado en sesiones de Codex. Se
necesita una memoria estable para retomar el proyecto sin depender de
conversaciones previas.

### Plan propuesto

- Crear `AGENTS.md` con reglas de trabajo para Codex.

- Crear `TAREAS.md` como backlog vivo con tareas en formato ficha.

- Crear `documentacion/HITOS.md` para registrar avances y decisiones importantes.

- Crear `documentacion/versiones/` para registros puntuales de cambios relevantes.

- Ajustar minimamente `README.qmd` para enlazar esta memoria del proyecto.

### Criterio de finalizacion

La estructura minima de memoria queda creada, enlazada desde el
README y lista para usarse en futuras sesiones.

### Notas

Si `TAREAS.md` crece demasiado, las tareas finalizadas
antiguas se pueden migrar a `TAREAS_FINALIZADAS.md`.

La estructura quedo creada y enlazada desde
`README.qmd`.
